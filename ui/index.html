So funktioniert bskitool

  
    
    
  1. Kurs als Markdown-Datei in kurse/<name>/kurs.md schreiben (Bilder und Dateien daneben). Vorlage: kurse/beispiel/, Referenz: docs/FORMAT.md, ausführliche Anleitung: docs/ANLEITUNG.md.
    2. 
    
  2. Reiter Kurs bauen: Datei wählen → Vorschau ansehen.
    3. 
    
  3. Reiter Einstellungen: einmal Zugangsdaten eintragen und anmelden.
    4. 
    
  4. Trockenlauf, dann Jetzt einspielen. Danach in Brightspace freigeben.
    5.

Was die API nicht kann

  
    
    
  • Quizfragen lassen sich nicht per API anlegen. bskitool legt die Quiz-Hülle an und schreibt die Fragen als
      D2L-CSV nach ausgabe/<kurs>/fragen/ – die importierst du in die Fragensammlung. Selbstchecks in
      Seiten funktionieren dagegen sofort.
    • 
    
  • Wenn die API gar nicht mitspielt: Als .imscc exportieren und in Brightspace importieren.
    • 
    
  • Nach jedem Einspielen liegt in ausgabe/<kurs>/noch-zu-tun.html, was von Hand bleibt.
